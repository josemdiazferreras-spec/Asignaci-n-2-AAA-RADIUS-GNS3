# Comandos y procedimientos empleados

Se documentan los comandos observados en los `running-config` y las pruebas de esta práctica. **No son scripts ejecutables automáticamente**: se entregan como referencia técnica. Para reproducir la configuración, consultar además los archivos de `configs/`, que son exportaciones completas sanitizadas.

- [`01-AAA-RADIUS-SSH-CISCO.txt`](01-AAA-RADIUS-SSH-CISCO.txt): fragmentos de la configuración aplicada en ambos equipos, extraídos de sus running-configs finales.
- [`02-VERIFICACIONES-CISCO.txt`](02-VERIFICACIONES-CISCO.txt): comandos de comprobación utilizados y resultados esperados.
- [`03-NPS-AD-PROCEDIMIENTO.md`](03-NPS-AD-PROCEDIMIENTO.md): configuración mediante interfaz gráfica (no se ejecutó un script PowerShell).

**Seguridad:** No se incluyen contraseñas, claves RADIUS ni hashes reales. Los marcadores `<...>` no deben copiarse como secretos funcionales. Los comandos de prueba usan cuentas de laboratorio sin mostrar contraseñas.
